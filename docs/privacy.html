Privacy Policy

Last updated: September 22, 2026.

This Privacy Policy explains how The Business Flow uses information obtained through Google OAuth and YouTube API Services for its internal video publishing automation.

Data we access

The application requests permission to upload videos to YouTube and to read basic information about the authenticated YouTube channel and uploaded videos. OAuth credentials are used only to authenticate the authorized channel owner.

How data is used

  • To confirm that the automation is connected to the correct The Business Flow YouTube channel.
  • To upload original videos and thumbnails.
  • To validate uploaded-video metadata and publishing status.
  • To schedule videos for future publication.

Storage and security

OAuth client credentials and refresh tokens are stored as encrypted GitHub Actions Secrets and are not committed to the public source repository. The application does not sell Google user data or use it for advertising.

Sharing

Google user data is not sold, rented, or shared with advertisers or unrelated third parties. Data is used only by the internal automation and service providers required to operate the workflow, such as GitHub Actions and Google/YouTube API Services.

Retention and deletion

The application keeps only the authorization data necessary to operate the publishing workflow. If access is revoked or the integration is discontinued, stored authorization credentials are removed promptly. Any stored YouTube API data that is no longer authorized will be deleted as soon as practical and no later than 30 calendar days after revocation.

Revoking access

The authorized Google account owner can revoke the application's access at any time from the Google Account permissions page: Google Account — Third-party access.

YouTube and Google policies

Use of YouTube API Services is subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions about this policy can be sent to thebusinessflowtv@gmail.com.
